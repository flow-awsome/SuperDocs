# 열려있는 질문

사용자(또는 의사결정권자)의 답을 기다리는 항목만 남긴다. 답이 나오면 **즉시 이 목록에서 제거**하고, 답과 근거는 [07-decisions](../07-decisions/README.md) 또는 관련 [10-consulting](../10-consulting/README.md) 문서로 옮긴다. 이 파일은 항상 짧아야 한다 — 길어진다는 것은 결정이 밀리고 있다는 신호다.

**상한: 20건.** 20건을 넘기면 새 질문을 추가하기 전에 가장 오래된 항목부터 사용자에게 직접 확인을 요청한다 — 답을 못 받아 방치된 질문이 계속 쌓이게 두지 않는다. [11-audit/02-audit-closure-log](../11-audit/02-audit-closure-log/README.md)에서 "패치완료(미검증)" 상태로 오래 머무는 항목도 여기로 옮겨와 재검증을 요청한다.

|---|---|---|---|
| | | 긴급/보통/낮음 | |

없으면 "현재 대기 중인 질문 없음"이라고 명시한다.
