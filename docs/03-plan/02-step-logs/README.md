# 02-step-logs — 스텝 로그

스텝 실행 중 발생한 세부 진행 기록. "계획대로 됐는가, 무엇이 달랐는가"를 시간순으로 남긴다.

## 파일명 규칙

`phase-<번호>-step-<번호>-log.md`

## 템플릿

[_template-step-log.md](_template-step-log.md)

## 작성 원칙

- 의미없는 중간보고를 나열하지 않는다 — 결정이 필요했던 지점, 계획과 달라진 지점, 다음 세션이 알아야 할 맥락 위주로 기록한다.
- 트러블을 겪었다면 이 로그에 요약만 남기고 상세 대응은 [08-troubleshooting](../../08-troubleshooting/README.md)에 남긴 뒤 링크한다.
