# 03-plan — 플랜

페이즈 → 스텝 → 스텝 로그의 3단계로 실행 계획을 관리한다. "계획"과 "실제 진행 기록"을 분리한다 — 계획은 이 폴더, 실제 있었던 일은 [06-history](../06-history/README.md).

## 하위 구조

| 폴더 | 단위 | 내용 |
|---|---|---|
| [00-phases](00-phases/README.md) | 페이즈 (수 주~수개월) | 프로젝트를 나눈 큰 덩어리, 목표와 범위 |
| [01-steps](01-steps/README.md) | 스텝 (하루~수일) | 페이즈를 나눈 실행 단위 작업 |
| [02-step-logs](02-step-logs/README.md) | 스텝 로그 (실행 시점) | 각 스텝 실행 중 발생한 세부 기록 |

## 계층 관계

```
Phase (페이즈)
 └─ Step (스텝)
     └─ Step Log (스텝 로그)
```

## 사용 원칙

- 새 작업을 시작하기 전 현재 페이즈/스텝이 무엇인지 이 폴더에서 먼저 확인한다.
- 계획이 실제와 어긋나면 계획 문서를 갱신하고, 그 변경을 [06-history/01-plan-changelog](../06-history/01-plan-changelog/README.md)에 남긴다.
- 스텝 로그는 스텝 완료 후에도 삭제하지 않는다 (히스토리 가치).
