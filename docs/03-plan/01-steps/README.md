# 01-steps — 스텝

페이즈를 실행 가능한 단위로 쪼갠 작업. 하나의 스텝은 보통 하루~수일 내 완료 가능한 크기여야 한다.

## 파일명 규칙

`phase-<번호>-step-<번호>-<슬러그>.md`

## 템플릿

[_template-step.md](_template-step.md)

## 작성 원칙

- 스텝은 완료 조건(Definition of Done)이 명확해야 한다.
- 스텝 실행 중 세부 기록은 이 파일에 누적하지 않고 [02-step-logs](../02-step-logs/README.md)에 남긴다 (스텝 문서 자체는 계획으로 깔끔하게 유지).
