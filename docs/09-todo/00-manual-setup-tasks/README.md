# 00-manual-setup-tasks — 수동 설정 작업

AI/개발팀이 대신 처리할 수 없어 사용자가 직접 해야 하는 작업 목록.

## 템플릿

[_template-manual-task.md](_template-manual-task.md)

## 전형적인 예시

- AWS 계정/IAM 권한 발급
- 도메인 구매 및 DNS 설정
- 제3자 서비스(결제, 이메일 등) API 키 발급
- 법적/컴플라이언스 승인
- 프로덕션 배포 승인

## 작성 원칙

- 작업 하나당 명확한 완료 조건과 완료 후 AI에게 알려줄 정보(예: 발급된 키를 어디에 저장했는지)를 명시한다.
- 완료된 항목은 삭제하지 않고 상태를 "완료"로 표시해 이력으로 남긴다.
