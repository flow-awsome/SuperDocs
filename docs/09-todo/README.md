# 09-todo — 투두리스트 & 업무 통신

사용자가 수동으로 세팅해야 하거나 직접 처리해야 하는 사항, 그리고 개발팀(AI 포함)과 사용자 간의 상세한 업무 통신을 담당한다.

## 하위 구조

| 폴더 | 내용 |
|---|---|
| [00-manual-setup-tasks](00-manual-setup-tasks/README.md) | 사용자가 수동으로 해야 하는 설정/작업 (AI가 대신할 수 없는 것) |
| [01-dev-communication-log](01-dev-communication-log/README.md) | 개발팀-사용자 간 질의/요청/통지 로그 |

## 이 폴더가 존재하는 이유

AI는 API 키 발급, 결제 정보 입력, 도메인 구매, 제3자 승인처럼 **대신 할 수 없는 작업**을 만나면 이 폴더에 명확한 작업 항목으로 남기고 다음 가능한 작업으로 넘어간다 (막연히 기다리지 않는다).
