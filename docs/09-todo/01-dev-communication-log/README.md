# 01-dev-communication-log — 개발-사용자 통신 로그

개발팀(AI 포함)이 사용자에게 물어봐야 할 것, 통지해야 할 것, 승인받아야 할 것을 구조화해서 남긴다. 대화 중 스쳐 지나가는 질문이 아니라 **추적 가능한 질의응답**이 필요할 때 사용한다.

## 파일명 규칙

`YYYY-MM-DD-<슬러그>.md`

## [10-consulting](../../10-consulting/README.md)와의 차이

- 10-consulting은 서비스의 방향/의도에 대한 깊이 있는 논의.
- 이 폴더는 더 실무적/사무적인 통지·확인·승인 요청 (예: "이 라이브러리 버전을 올려도 될까요?", "이번 주 배포 승인해주세요").
- 판별이 애매하면: **답이 [07-decisions](../../07-decisions/README.md)로 이어질 만한 질문이면 10-consulting**, **단순 완료/승인 확인이면 여기(09-todo)**.
