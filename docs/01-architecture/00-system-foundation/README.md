# 00-system-foundation — 시스템 기초

이 시스템이 딛고 서는 기반: 언어, 프레임워크, 런타임, 인프라 베이스라인, 코딩 컨벤션. [mastery/00-initial-intake/02-tech-stack-baseline.md](../../../mastery/00-initial-intake/02-tech-stack-baseline.md)에서 확정된 내용이 여기로 승격되어 정착한다.

## 파일

- [tech-stack-and-conventions.md](tech-stack-and-conventions.md) — 확정된 스택, 버전, 코딩/네이밍 컨벤션
- [environment-and-infra-baseline.md](environment-and-infra-baseline.md) — 로컬/스테이징/프로덕션 환경 구성, AWS 인프라 베이스라인

## 갱신 시점

스택 버전 업그레이드, 컨벤션 변경, 인프라 구성 변경이 있을 때만 갱신한다. 페이즈마다 바뀌는 내용이 아니므로 변경 빈도가 낮아야 정상이다 — 자주 바뀐다면 [08-troubleshooting](../../08-troubleshooting/README.md)에 원인을 살펴볼 가치가 있다.
