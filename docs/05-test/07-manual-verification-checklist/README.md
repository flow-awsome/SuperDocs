# 07-manual-verification-checklist — 수동 검증 체크리스트

자동화하지 않았거나 자동화할 수 없는 항목을 사람이 체크하는 리스트.

## 템플릿

[_template-manual-checklist.md](_template-manual-checklist.md)

## 작성 원칙

- 체크리스트 항목은 "예/아니오"로 명확히 판정 가능해야 한다.
- 반복적으로 쓰는 체크리스트(배포 전 체크리스트 등)는 별도 파일로 고정한다.
- 자동화가 가능해진 항목은 상위 검증 폴더(00~06)로 이전하고 여기서 제거한다.
