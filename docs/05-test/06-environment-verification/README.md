# 06-environment-verification — 현장 환경 검증

실제 staging/production 환경에서만 드러나는 문제를 검증한다 (로컬/CI 환경과의 차이에서 발생).

## 검증 항목

| 항목 | 내용 |
|---|---|
| 환경변수/시크릿 | 실제 환경에 올바르게 주입되는지 |
| 네트워크/방화벽 | VPC, 보안그룹 설정이 의도대로 동작하는지 |
| 배포 파이프라인 | CI/CD가 실제로 무중단 배포되는지 |
| 모니터링/알람 | CloudWatch 알람이 실제로 발동하는지 |
| 롤백 절차 | 실제 롤백이 절차대로 동작하는지 |

## AI가 직접 확인할 수 없는 항목

AWS 콘솔 접근 권한이 없거나 실제 프로덕션 트래픽에 대한 접근이 없는 AI는 위 항목 중 일부(네트워크/방화벽 실제 동작, 모니터링/알람 실제 발동)를 직접 확인할 수 없다. 이런 항목은 추측으로 "확인함" 처리하지 않고 [09-todo/00-manual-setup-tasks](../../09-todo/00-manual-setup-tasks/README.md)에 사람이 수행할 작업으로 명시적으로 등록한다.

## 결과 기록

여기서 발견된 환경 특유의 문제는 [08-troubleshooting](../../08-troubleshooting/README.md)에 반드시 기록한다 — 같은 문제가 다음 배포에서 반복되지 않도록.
