# 요구사항 설문: (고객코드)

이 고객사만의 요구사항, 기존 워크플로우, baseline과 다르게 필요한 부분을 정리한다. 질문 구조는 [mastery/00-initial-intake/01-project-questionnaire.md](../../../mastery/00-initial-intake/01-project-questionnaire.md)를 참고하되, "이 고객사에게만 해당하는" 질문으로 좁힌다.

## 질문과 답변

- 이 고객사의 기존 업무 흐름은 어떻게 되는가?
- baseline 기능 중 이 고객사에게 불필요하거나 부족한 것은?
- 이 고객사만의 규제/보안 요구사항이 있는가?

답변에서 baseline과 충돌하는 지점이 발견되면 [conflict-and-improvement-log.md](conflict-and-improvement-log.md)로 옮긴다.
