# 03-discussion-log — 자유 토론 로그

아직 질문 형태로 정리되지 않은 열린 토론, 아이디어, 브레인스토밍을 담는다. 서비스의 전체적인 흐름이나 방향에 대해 사용자와 AI가 편하게 논의하는 공간이며, 여기서 나온 내용이 성숙하면 다른 폴더(시나리오, 결정, 플랜)로 승격된다.

## 언제 쓰는가

- "이런 방향은 어떨까?" 같은 탐색적 논의
- 아직 결정할 준비가 안 된 아이디어를 잊지 않기 위한 기록
- 여러 페이즈에 걸쳐 반복적으로 떠오르는 주제의 누적 논의

## 파일명 규칙

`topic-<슬러그>.md` — 하나의 주제는 하나의 파일에 시간순으로 누적한다 (컨설팅 세션 파일과 달리 이 폴더는 누적형 허용).

## 승격 기준

논의가 다음 상태가 되면 다른 폴더로 옮긴다:

- 구체적 갈림길이 생겼다 → [02-decision-interviews](../02-decision-interviews/README.md)
- 서비스 동작 방식이 확정됐다 → [02-scenario](../../02-scenario/README.md)
- 실행 계획이 되었다 → [03-plan](../../03-plan/README.md)
