# 01-phase-consulting — 페이즈 단위 컨설팅

각 [페이즈](../../03-plan/00-phases/README.md)의 시작과 종료 시점에 진행하는 컨설팅 세션 기록이다. 목적: 방향이 여전히 유효한지 재확인하고, 다음 페이즈 스코프를 조정한다.

## 언제 만드는가

- 페이즈 착수 직전 (킥오프 컨설팅) — **단, 프로젝트 첫 페이즈의 킥오프는 [mastery/00-initial-intake](../../../mastery/00-initial-intake/README.md) 인터뷰가 이미 그 역할을 했다면 생략한다.** 인터뷰 이후 스코프가 크게 안 바뀌었으면 별도 세션을 또 만들지 않는다.
- 페이즈 종료 직후 (회고 + 다음 페이즈 방향 컨설팅)
- 페이즈 도중 중대한 방향 전환이 필요할 때
