# 흐름 카탈로그 (마스터 인덱스)

이 폴더의 모든 흐름을 역할별 × 상태별로 한눈에 본다. 새 흐름이 떠오르면 상세 파일을 만들기 전에 **먼저 이 표에 한 줄부터 추가**한다 — 아직 구현 계획이 없어도 "있어야 할 흐름"으로 존재를 남기는 것 자체가 이 카탈로그의 목적이다.

## 갱신 원칙

- 구현이 끝났다고 표에서 행을 지우지 않는다 — 상태만 "구현됨"으로 바꾸고 구현 위치 링크를 채운다.
- 요구사항이 바뀌어 재검토가 필요하면 "변경검토중"으로 바꾸고 [10-consulting/03-discussion-log](../../10-consulting/03-discussion-log/README.md)에 논의를 남긴다.
- 이 표 자체가 방대해지면(행 50개 이상) 역할별 표를 각각 별도 파일로 분리하고 여기는 그 파일들의 인덱스로 축소한다 ([00-control-tower/doc-governance-policy.md](../../00-control-tower/doc-governance-policy.md)의 크기 예산 원칙 적용).
